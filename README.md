# tibo rest plugin

中文 · [English](README.en.md)

屏幕顶部的倒计时胶囊，显示 Tibo 预告的 Codex reset 和 reset 卡到期时间，点击展开详情。支持 Mac、Windows，以及中英文界面。

![胶囊预览](mac/capsule.svg)

## 使用

安装 Skill 后，对 Codex 说 **“查询codex重置”** 或 **“查询tibo重置”**。

Skill 下载对应系统的程序，查询 Tibo 最新帖子与评论，直接设置倒计时，无需编辑配置文件。界面跟随系统语言，也可让 Codex 切换中文或英文。

## 安装 Skill

将以下内容发给 Codex：

```text
$skill-installer install https://github.com/yifan233/tibo-rest-plugin/tree/main/skill/tibo-reset
```
