# tibo rest plugin

[中文](README.md) · English

A compact countdown capsule at the top of your screen for Tibo's announced Codex resets and reset credit expiry. Click to expand. Supports Mac, Windows, and Chinese/English interfaces.

![Capsule preview](mac/capsule.svg)

## Use

After installing the skill, tell Codex **“check Codex reset”** or **“check Tibo reset”**.

The skill downloads the app for your system, checks Tibo's latest posts and comments, and sets the countdown directly. No configuration files to edit. The interface follows your system language; ask Codex to switch to English or Chinese.

## Install the skill

Send this to Codex:

```text
$skill-installer install https://github.com/yifan233/tibo-rest-plugin/tree/main/skill/tibo-reset
```
